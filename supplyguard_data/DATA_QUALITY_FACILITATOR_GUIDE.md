# SupplyGuard Data Quality Facilitator Guide

The raw data contains hidden, deliberate data-quality problems.

Learners should discover these through profiling, validation,
joins and business-rule checks.

## Intended problems

- Missing values, blank strings and whitespace-only fields
- Duplicate records
- Duplicate IDs with conflicting information
- Inconsistent casing and whitespace
- Inconsistent category labels
- Mixed and invalid date formats
- Numeric strings and currency symbols
- Negative and zero numeric values
- Impossible ratings and hours
- Outliers
- Invalid customer, warehouse, shipment, driver and vehicle references
- Deliveries occurring before shipment dates
- Driver experience greater than age
- Unrealistic vehicle mileage
- Invalid vehicle capacity and maintenance scores
- Invalid warehouse capacity
- Inconsistent boolean representation

Do not give learners this guide at the start of the sprint.
Use it as the facilitator marking/checking guide.
